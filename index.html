Network Audit Tool v1.5
Herramienta CLI de reconocimiento activo · Python 3
Python 3 socket subprocess Cybersecurity CLI
¿Qué hace?

Herramienta de auditoría de red de línea de comandos que automatiza el reconocimiento activo de hosts. Ejecuta 4 fases secuenciales y genera un reporte estructurado en JSON al finalizar.

Flujo de ejecución — 4 fases
01
OS Fingerprinting
Envía un ping ICMP y analiza el TTL de la respuesta. TTL ≤ 64 → Linux/Unix · TTL ≤ 128 → Windows · TTL > 128 → Cisco/Solaris.
02
Port Scanning
Intenta conexión TCP a 10 puertos críticos (21, 22, 23, 80, 135, 443, 445, 3306, 3389, 8080) con timeout 0.4s usando socket.connect_ex().
03
Banner Grabbing
Para cada puerto abierto captura el banner del servicio. En HTTP envía un HEAD request para forzar respuesta. Retorna la primera línea recibida.
04
Risk Analysis + JSON Export
Cruza puertos abiertos contra una DB local de vulnerabilidades (BAJO / MEDIO / ALTO / CRÍTICO) y exporta todo a auditoria_IP.json.

Restricciones
Solo para redes propias o con autorización escrita. El escaneo no autorizado es ilegal.
Requiere Python 3.6+ y permisos de subprocesos para ICMP ping.
TCP connect scan — no requiere privilegios de administrador (sin raw sockets).
Escanea 10 puertos predefinidos. No reemplaza Nmap para reconocimiento completo.
Compatible con Windows, Linux y macOS. Detecta el SO del host para adaptar el ping.
